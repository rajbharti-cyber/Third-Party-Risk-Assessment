# 🏛️ Governance Folder

This folder contains governance-focused documentation related to third-party risk management (TPRM), including:

- Vendor onboarding governance
- Risk ownership definitions
- Escalation procedures
- Third-party oversight processes
- Risk acceptance workflows
- Compliance coordination
- Executive reporting support

The purpose of this documentation is to ensure vendors are evaluated using consistent, risk-based governance principles aligned with enterprise security and compliance expectations.
