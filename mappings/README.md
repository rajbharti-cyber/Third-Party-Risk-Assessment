# 🔗 Mappings Folder

This folder contains control mappings and governance alignment documentation related to third-party/vendor risk management.

Mappings may include:

- ISO 27001 vendor control alignment
- NIST CSF mapping
- CIS Controls correlation
- Risk-to-control traceability
- Compliance requirement mapping
- Security governance references

The goal is to demonstrate structured alignment between third-party security assessments and recognized governance frameworks.
