# 🔗 ISO 27001 Vendor Control Mapping

## 📌 Purpose

This document demonstrates how third-party/vendor security governance controls can be mapped to ISO 27001 requirements to support compliance alignment, audit readiness, and governance traceability.

The objective is to ensure vendor risk management practices align with recognized information security governance standards.

---

# 🎯 Governance Objectives

- Improve vendor governance visibility
- Support compliance alignment
- Enhance audit defensibility
- Demonstrate control traceability
- Strengthen third-party oversight

---

# 📊 ISO 27001 Vendor Control Mapping

| ISO 27001 Control | Vendor Governance Control |
|---|---|
| A.5.19 Supplier Relationships | Vendor onboarding governance |
| A.5.20 Supplier Agreements | Security clauses in contracts |
| A.5.21 ICT Supply Chain | Vendor security reviews |
| A.5.22 Supplier Monitoring | Ongoing vendor assessments |
| A.5.23 Cloud Service Security | Cloud vendor governance |
| A.5.15 Access Control | Vendor access restrictions |
| A.8.15 Logging | Vendor activity monitoring |
| A.5.24 Incident Management | Vendor incident escalation |
| A.5.30 ICT Readiness | Vendor resilience planning |

# 🛡️ Governance Mapping Areas
